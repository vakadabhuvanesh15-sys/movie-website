# CineView — Inception Movie Page

A responsive one-page movie information website for the film *Inception*. It is built using only HTML5 and CSS3.

## Features

- Sticky navigation with anchor links
- Hero poster and movie details
- Story synopsis and production information
- Six cast cards
- IMDb, audience and critics ratings
- Responsive YouTube trailer
- Related movie posters with hover effects
- Footer links
- Desktop, tablet and mobile layouts

## Run Locally

1. Open the project folder.
2. Double-click `index.html`, or open it with the Live Server extension in VS Code.

## Upload to GitHub

1. Create a new repository on GitHub.
2. Open this project folder in VS Code.
3. Open the VS Code terminal.
4. Run:
   ```bash
   git init
   git add .
   git commit -m "Create movie information website"
   git branch -M main
   git remote add origin YOUR_REPOSITORY_URL
   git push -u origin main
   ```

Replace `YOUR_REPOSITORY_URL` with the HTTPS URL of your GitHub repository.

## Enable GitHub Pages

1. Open the repository on GitHub.
2. Click **Settings**.
3. Select **Pages** from the left menu.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder.
6. Click **Save**.
7. Wait one minute, then open the Pages URL shown by GitHub.
